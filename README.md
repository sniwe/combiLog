# combiLog

Project root for combiLog.

## Layout

- `mgmt/`: project governance and thread tracking
- `src/`: source code
- `mgmt/projMap/map/`: plain-English project spec tree with `leaf.txt` files and fenced front matter blocks

## Run

- `npm start`: blank page server plus Cloudflare quick tunnel
- `npm run dev`: same auto-tunneled server
